# 🏦 Loan Management System (LMS)

[![Project Demo](https://img.youtube.com/vi/rv4GaoEvZDM/maxresdefault.jpg)](https://youtu.be/rv4GaoEvZDM)

This repository contains the complete Loan Management System built with a Node.js/Express backend and a Next.js/React frontend.

## 🚀 Live Demo
- **Frontend App:** https://lms-liard-six.vercel.app
- **Backend API:** https://lms-42nj.onrender.com

## 📁 Project Structure
- `/lms-frontend` - The Next.js frontend application
- `/lms-backend` - The Node.js/Express backend API

Please refer to the `README.md` files inside the individual folders for local setup instructions and architectural details.
